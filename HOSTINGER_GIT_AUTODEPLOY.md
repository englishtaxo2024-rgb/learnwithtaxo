# Hostinger Git Auto-Deploy

Use this when Hostinger must deploy the live Learn with Taxo website automatically from GitHub.

## Branches

- `main`: full React/Vite source code.
- `hostinger-static`: built website only, generated by GitHub Actions from `npm run build`.

Hostinger must deploy `hostinger-static`, not `main`.

## Current Build Flow

1. Push source changes to `main`.
2. GitHub Actions runs `.github/workflows/deploy-hostinger-static.yml`.
3. The workflow uses Node 20.
4. The workflow runs `npm install`.
5. The workflow runs `npm run build`.
6. The workflow verifies:
   - `dist/index.html`
   - `dist/404.html`
   - `dist/assets/`
   - built JS and CSS files
   - official logo files
   - visual image folders
7. The workflow publishes only `dist/` to `hostinger-static`.
8. Hostinger auto-deploys `hostinger-static` when auto-deployment is enabled.

## Hostinger Setup

1. Go to Hostinger hPanel.
2. Open `Websites` -> `learnwithtaxo.com`.
3. Go to `Advanced` -> `Git`.
4. Disconnect the current Git deployment if it is connected to `main`.
5. Reconnect GitHub repository:
   `englishtaxo2024-rgb/learnwithtaxo`
6. Choose branch:
   `hostinger-static`
7. Root directory:
   `public_html`
8. Enable auto-deployment.
9. Click `Deploy` or `Redeploy` if Hostinger does not update automatically.
10. Open:
    `https://www.learnwithtaxo.com?fresh=1`

## Expected `hostinger-static` Branch Root

The `hostinger-static` branch root should contain:

- `.htaccess`
- `.nojekyll`
- `index.html`
- `404.html`
- `assets/`
- any other static files generated inside `dist/`

It must not contain:

- `src/`
- `server/`
- `public/`
- `package.json`
- `package-lock.json`
- `node_modules/`
- `.env`
- `.env.example`
- README source files
- Vite/Tailwind/PostCSS config files

## Notes

No local npm is required for deployment when GitHub Actions is enabled. The build happens inside GitHub Actions, then Hostinger pulls the generated `hostinger-static` branch.
